2. Module Architecture & Call Graph

🌐 Entry & Dispatcher (`main.py` & `core/pipeline.py`)

process_api() main.py
IN: HTTP POST /api/process
OUT: probe_media_file()
OUT: resolve_auto_quality()
OUT: process_media()
Handles uploaded file, parses key options, triggers pipeline.
resolve_auto_quality() main.py
IN: process_api()
OUT: probe_media_file()
Auto-detects optimal codecs, formats, bitrates if set to 'auto'.
process_media() pipeline.py
IN: process_api()
OUT: process_image_file() (for images)
OUT: process_audio_file() (for standalone audio)
OUT: process_video_file() (for videos)
Master router delegating processing to appropriate handler.

🎬 Video Engine (`core/video_processor.py`)

process_video_file() video_processor.py
IN: process_media()
OUT: process_audio_file() (Dual-track / background)
OUT: get_blocks(), get_outer_blocks()
OUT: seeded_shuffle()
OUT: export_grid_to_svg()
OUT: FFmpeg subprocess (stdin rawvideo piping)
Executes normal & center video block scrambling and audio extraction.
_adjust_audio_length() video_processor.py
IN: process_video_file()
OUT: Returns padded or looped audio array
Crops, loops, or pads audio array to fit target frame duration.

🖼️ Image Engine (`core/image_processor.py`)

process_image_file() image_processor.py
IN: process_media()
OUT: get_blocks(), get_outer_blocks()
OUT: seeded_shuffle()
OUT: save_image()
Performs matrix block shuffling for single frame images.
save_image() image_processor.py
IN: process_image_file()
OUT: Pillow / OpenCV disk write
High-quality image exporter for JPG, PNG, AVIF, WEBP.

🎵 Audio DSP Engine (`core/audio.py`)

process_audio_file() audio.py
IN: process_media(), process_video_file()
OUT: process_band_scramble()
OUT: process_combined()
OUT: process_inversion()
Main audio track dispatcher (supports multichannel & selective track).
process_band_scramble() audio.py
IN: process_audio_file()
OUT: FFT spectrum split and band permuted array
Splits frequency spectrum into N bands and scrambles them.
process_combined() audio.py
IN: process_audio_file()
OUT: get_permutation(), numpy_lowpass_filter()
Combines carrier modulation with block FFT band scrambling.
process_inversion() audio.py
IN: process_audio_file()
OUT: numpy_lowpass_filter()
Traditional time-domain cosine ring modulation / frequency inversion.
numpy_lowpass_filter() audio.py
IN: process_combined(), process_inversion()
OUT: FFT irfft audio signal
Hann-smoothed FFT lowpass filter eliminating carrier harmonics.
mulberry32() / get_permutation() audio.py
IN: process_combined()
OUT: Permutation index array
Deterministic PRNG and array permutation generator.

🛠️ Core Support Utilities

Module Function Called By Output / Purpose
grid_utils.py get_blocks() video_processor, image_processor, svg_generator Calculates exact gapless (x1, y1, x2, y2) tile coordinates.
grid_utils.py get_outer_blocks() video_processor, image_processor, svg_generator Splits grid into inner center overlay and outer background regions.
grid_utils.py find_best_grid() video_processor, image_processor, svg_generator Finds optimal (cols, rows) ratio for N outer blocks.
crypto.py seeded_shuffle() video_processor, image_processor, svg_generator Deterministic PRNG array shuffling using seed string.
crypto.py hash_str() main.py Hashes key/seed string into uint32 seed integer.
crypto.py clean_key() main.py Strips extra spaces and "KEY:" prefixes from key strings.
svg_generator.py export_grid_to_svg() video_processor, image_processor Generates visual SVG overlay layout file.
svg_generator.py export_scrambled_grid_to_svg() video_processor, image_processor Generates sequence-numbered permuted SVG grid file.
metadata_prober.py probe_media_file() main.py, video_processor Probes codecs, bitrates, resolution, sample rates (via PyAV/FFmpeg).
tempdir.py get_temp_file_path() pipeline.py, video_processor Manages auto-cleaning process-isolated temporary working directory.
logger.py LiveDebugger All modules (via @LiveDebugger.trace) Real-time console debugger & exception root cause analyzer.
